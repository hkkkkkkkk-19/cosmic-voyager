# Cosmic Voyager

An immersive AI-powered space exploration platform featuring real-time tracking systems, futuristic visualizations, and interactive astronomy modules.

## Overview

Cosmic Voyager is a modern web application designed to provide an interactive and visually immersive space exploration experience. The platform combines astronomy-inspired interfaces, real-time tracking systems, and AI-driven components into a unified futuristic environment.

The project focuses on responsive design, smooth animations, modular architecture, and scalable frontend engineering practices.

---

## Core Features

### Real-Time ISS Tracking
Track the International Space Station with dynamic visual representation and live interaction modules.

### Meteor Activity Monitoring
Visualize and explore meteor-related information through interactive dashboards.

### AI Navigator
An intelligent futuristic assistant designed to enhance user interaction and exploration flow.

### Aurora Dashboard
Space-inspired analytics and atmospheric visual experiences integrated into a responsive dashboard.

### Astro Reports
Generate astronomy-themed informational displays and structured visual insights.

### Interactive Space Environment
Custom cursor effects, animated star backgrounds, and cinematic transitions for immersive user experience.

### Space Travel Hub
Centralized exploration module for space destinations, information systems, and interactive navigation.

## Installation

Clone the repository:

```bash
git clone https://github.com/hkkkkkkkk-19/cosmic-voyager.git
```

Navigate to the project directory:

```bash
cd cosmic-voyager
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
